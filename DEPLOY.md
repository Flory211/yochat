# Инструкция по деплою ЁЧат на Railway

## Шаг 1: Регистрация на Railway

1. Откройте https://railway.app
2. Нажмите **"Login"** → **"Sign in with GitHub"**
3. Если нет GitHub аккаунта:
   - Создайте бесплатно на https://github.com
   - Подтвердите email
   - Вернитесь на Railway

## Шаг 2: Создание проекта на Railway

1. После входа нажмите **"New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. Подключите ваш GitHub аккаунт
4. Создайте новый репозиторий для ЁЧат (или используйте существующий)

## Шаг 3: Загрузка кода на GitHub

### Вариант A: Через GitHub Desktop (проще)
1. Скачайте GitHub Desktop: https://desktop.github.com
2. Войдите через GitHub аккаунт
3. Нажмите **"Add"** → **"Create New Repository"**
4. Выберите папку `C:\ЁЧат\yochat`
5. Нажмите **"Publish repository"**

### Вариант B: Через командную строку
```bash
cd C:\ЁЧат\yochat
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/yochat.git
git push -u origin main
```

## Шаг 4: Деплой на Railway

1. На Railway выберите ваш репозиторий
2. Railway автоматически определит Node.js проект
3. Нажмите **"Deploy"**
4. Ждите 2-5 минут, пока проект соберется

## Шаг 5: Настройка переменных окружения

1. В проекте Railway нажмите **"Variables"**
2. Добавьте переменную:
   - `JWT_SECRET` = (ваш секретный ключ)
   - `NODE_ENV` = `production`
   - `PORT` = `3000`

## Шаг 6: Получение адреса

1. После успешного деплоя нажмите **"Settings"**
2. Найдите **"Domains"**
3. Скопируйте адрес (например: `yochat-production.up.railway.app`)
4. Этот адрес можно давать друзьям!

## Шаг 7: Настройка базы данных

⚠️ **Важно:** Railway использует временную файловую систему. База данных SQLite будет удаляться при каждом деплое!

### Решение: Использовать PostgreSQL (бесплатно на Railway)

1. В проекте Railway нажмите **"New"** → **"Database"** → **"Add PostgreSQL"**
2. Дождитесь создания базы данных
3. Railway автоматически добавит переменную `DATABASE_URL`
4. Нужно изменить код для работы с PostgreSQL вместо SQLite

## Альтернатива: Supabase (проще)

Если не хотите менять код на PostgreSQL, можно использовать **Supabase**:
- Бесплатно (500 МБ базы данных)
- Совместим с PostgreSQL
- Простая настройка
- https://supabase.com

## Что дальше?

После деплоя:
1. Дайте друзьям адрес сайта
2. Они смогут регистрироваться и входить
3. Вы (Leo) сможете управлять через админ-панель
4. Все данные будут сохраняться постоянно!

## Стоимость

Railway бесплатно дает:
- 500 часов работы в месяц (этого хватит для постоянного доступа)
- 5 ГБ трафика
- 1 ГБ базы данных

Для 15 пользователей этого более чем достаточно!
